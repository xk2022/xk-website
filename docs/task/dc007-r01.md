三系列 Modern／Heritage／Luxury 各 Home＋實際最大風險頁（原盤點為 Quotation），每頁至少三次冷載；門檻 TBT≤200ms、LCP≤2500ms、CLS≤0.1。原TBT中位數約1201–1553ms。保留字體與字重、視覺定位、所有內容／價格／功能／49路由／SEO／noindex／Privacy／標準A4、既有操作流程與根路徑靜態輸出。

不重新初始化，不改 npm 依賴／lockfile／平台設定，不新增後端或服務。效能策略依實證評估 Server／Client 邊界、bundle、hydration／long tasks、重複載入、圖片／字體／動畫及外部請求；不為清單形式任意拆 component、關閉功能或改變風格。保留 Inter／Noto Sans TC variable、原字型檔與 fallback／swap；若調整載入時機，明確揭露初始 fallback 時段與量測字型完成／CLS，不把延後工作到量測外冒作改善。

## 3. 編排與候選

Root 管理 Git、source freeze、六品質指令、build／server及獨占效能時窗；來源／JS及trace審查可平行唯讀，其他 Browser／axe／PDF／build 不與正式效能採樣同時執行。使用 `scripts/run-with-evidence.py` 保存真 OS exits，所有新工具／raw 放 `/tmp/xk-dc007-r01/`，分版本新目錄，不覆寫 FAIL。

先對原固定輸出同條件重新建立18次 before，記工具版本／profile／source／artifact。小候選先以三個 Modern Home cold 檢驗，未有效則修正或回退候選並保留實驗結果；採用後再跑完整18 after＋六組 warm，不拿pilot取代全驗。

Trace 證實中文字型子集分時完成後，多次全頁 Layout 為主要成本，React DOM 啟動有次要成本。先前兩個 Font Loading API 批次候選均未達標，原始程式、樣本及失敗紀錄保留；正式候選改採原生 CSS 字型載入，不新增字型 Client Component。將目前公開文字合併為相同 Noto Sans TC 版本的關鍵子集，保留完整 100–900 軸、原字重／字形及罕用字的原始分片。必須驗證來源、OFL、雜湊、Unicode 覆蓋、字形／寬度及變體選擇字元，不只比較字型名稱。

依實際排版成本評估原生 `content-visibility: auto`：僅於 screen 延遲首頁首段以外區塊、試算操作區／螢幕摘要預覽及 Footer 的離屏繪製；保留 DOM、可及性、錨點及鍵盤流程，不延遲 Hero、Header、風格切換或列印。實際採用以效能與操作／視覺回歸共同決定，不能把尚未執行的驗收寫成通過。
