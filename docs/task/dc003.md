# DC-003｜Modern 相容整合與 Design Collection

日期：2026-11-26。分支：`feature/design-collection-modern`。依 [DC-003 工作包](../01_design/design-collection/work-packages.md#dc003)、[架構](../01_design/design-collection/architecture.md) 與 [設計規範](../01_design/design-collection/design-systems.md) 執行；網站基準 `794b076` 已含 DC-002／[PR #33](https://github.com/xk2022/xk-website/pull/33) 及文件整理 PR #35。

## 範圍

- 唯一 root layout 保留 html／body、字體、共用 Metadata 與一次 WebSite JSON-LD；原 shell 與 routes 搬入 `(modern)`，URL、內容、現有 DOM 與互動保持。
- Modern facade 引用原全域 tokens／recipes；Frame 用 fragment，group not-found 只有內容，全域 not-found 才自帶 Frame，不使用 experimental globalNotFound。
- 新增 `/design-collection/`，正式 Modern 品牌 shell、三系列介紹；只有 Modern 有有效入口，Heritage／Luxury 為無連結「規劃中」。Gallery 自己包 Frame，不在共同 collection layout 包 Modern，避免未來新系列雙重 shell。
- Footer 目錄新增「設計系列」，接入公開 resolver；Header 與原服務／價格／作品／表單／試算／storage 保留。SEO／獨立 fixture／export guard 明確 17 頁，Gallery self-canonical，原 Modern 16 Metadata 不變。
- Root Pages basePath／assetPrefix 仍空字串，noindex/nofollow、Privacy／dev／Sitemap 保護、原依賴與 workflow 保留。不實作新系列或 StyleSwitcher。
