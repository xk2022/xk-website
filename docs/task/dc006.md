## 2. 功能與工程契約

1. 三套 Frame 的 Header 後、main 前新增共用 StyleSwitcher 正常文流區塊。維持各自 Header／版面／tokens、唯一 main／skip／Footer。列印隱藏新區塊，不改既有白色 A4、具名 page 或摘要。
2. 三項使用真實連結及可見系列名稱；目前風格以文字及 `aria-current` 辨識，不只用顏色。一般項目可 Tab／Enter、新分頁、複製網址及返回／前進；band 另有「比較三套版面」真入口前往 Gallery。沒有對應頁時使用明確標示的真實首頁 fallback，不默默冒充相同內容；Gallery／404 不是 Modern 內容頁。
3. 以同一 `resolveDesignHref` 及已發布 route model 產生所有站內目的地。Switcher 保持同 page key／合法 detail slug；只保留來源與目標頁都宣告的 semantic hash，丟棄不支援／private hash，從不攜帶 query 或個人欄位。既有外部來源、Showcase、mailto 保持原網址。
4. URL 是唯一風格來源；不新增 style preference、cookie、LocalStorage key 或個人資料持久化。Client 只接可序列化的公開導航模型，不能匯入完整 server-only 內容或以 pathname 決定整體 theme。
5. 提供可見個資提示；換風格後 Contact 草稿／Quotation 稱呼與專案名稱清空，原 `xk:quotation:v1` 只還原 IDs。拒絕 Clipboard／儲存仍可在記憶體操作及手動複製。保留既有 Activity／bfcache 清除。
6. Header／Mobile Navigation 接伺服器產生的導航資料；Footer 分組保留 49 頁且目的地由同一 resolver 產生；現有兩個 presentation CTA adapters 收斂為共用映射，未知網址不任意加前綴。保留 Modern 五項主導覽及原詢價行為。
7. Gallery 保留三張風格卡片各一個真實首頁入口，另加七個主要頁面的三風格對照入口，讓訪客可比較相同內容；說明三系列不是價格／服務級距。表格在 320px 可讀且不水平溢出。
8. 原生 details 手機選單展開時直接點 Switcher，不得因 pointerdown 提前收合、改變文流而丟失點擊；保留 Escape、focus 離開／回復、外部點擊及 breakpoint 行為。

## 3. 路由、SEO 與部署不變條件

清冊精確為 Modern 16＋Heritage 16＋Luxury 16＋Gallery 1＝49。所有 Footer 可鍵盤到達全部 49 頁；未知 style／slug、Privacy 草稿、dev、API、Sitemap 保持真正 404。既有 Contact3／Quotation3 控制項白名單維持，其餘 43 頁不新增表單。

Modern 原 16 頁 metadata 不變；Gallery self-canonical；32 展示頁 canonical 對 Modern、OG URL 對自身。全站 noindex/nofollow、唯一 WebSite JSON-LD、無 hreflang、無未核准 OG 圖、無 Sitemap。新增 screenshot 不是核准分享圖。

保留 Next.js 一般 production build 及 GitHub Actions → Pages 的 output export、空 basePath／assetPrefix、www 網域、trailingSlash、原資產。無 dependencies／lockfile、Backend、API、CMS、Analytics、workflow、DNS、Pages Source 或 Custom Domain 修改。
