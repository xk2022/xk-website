- 唯讀、可序列化且不可變的品牌／內容 DTO 與必要 by-ID 查詢；不變造事實、不帶 Lucide／React 呈現物件、不凍結或修改原 config。
- style／page key registry、嚴格 route describe／identify、只允已公開目的地的 href resolver，以及獨立 route fixture。
- Metadata adapter：Modern 輸出等同原 helper；planned 展示版描述其 Modern canonical／本身 OG URL，但不准安全入口輸出公開 metadata。

- Node.js 24 原生測試，test-only alias loader 相容既有 Next.js imports；不改正式 config imports、套件版本或 lockfile。
- 更新使用／契約文件、README／AGENTS／索引／實作紀錄，建立 [驗證報告](../reports/dc002-implementation.md)，Commit、Push、PR 等待審閱。
