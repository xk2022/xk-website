## 實作範圍

獨立 HeritageFrame／Header／Footer／Mobile Navigation、完整語意 tokens／recipes 與編輯式 composition。七主頁及九作品詳頁共 16 個 Heritage URL，與既有 17 頁合計 33；Luxury 不輸出。沿用所有資料來源、狀態、限制、價格、Logo、字體、共用 Contact／Quotation 純行為與標準 A4。

採已規劃的 `[style]` family，static params 僅 Heritage，兩種詳頁各列實際 3／6 slugs，未知 style／slug 真 404。每個頁面包一次 Frame，style layout 只回 children，避免 root 404 繼承第二個 Header／main／Footer；單一技術 root 的 fonts／Metadata／WebSite JSON-LD 不動。保留 www 根路徑、兩種建置、protected SEO 與 Privacy／dev／Sitemap 排除。

Heritage 同內容 canonical 對 Modern、OG 為其展示 URL。所有內鏈透過 resolver／page identity，外部作品／來源／mailto 保持原目的地。各 Footer 涵蓋所有 33 個發布 URL；Gallery 開啟已完成 Heritage、Luxury 保持無連結規劃卡。完整三系列 Switcher 屬 DC-006，本輪提供必要目錄與對應 Modern 返回入口。
