# XK Design Collection — 三套 Design System

版本：DC-001 / v1.0。日期：2026-11-26。狀態：**供審閱的設計規範，非已完成介面**。架構及品牌來源見 [架構規格](architecture.md)，實作順序見 [工作包](work-packages.md)。

## 1. 共通品牌與設計契約

同一份 XK SYSTEM／Xplore Kaleidoscope 公司資訊、服務、作品狀態、標語、聯絡與參考價格供三套介面使用。系列名稱是呈現方向，不代表新的公司、產品分類、團隊規模、定價等級或客戶成果。公司正式外框／署名規範繼續有效；展示主體新增角色屬提案，DC-004／DC-005 必須確認其適用範圍。

Logo 使用現行 [V2.0 原檔與來源紀錄](../../../public/brand/source/README.md)，依淺色／深色選正式主版、橫式、符號或反白版本；不拉伸、旋轉、自行染色、CSS filter、陰影或重畫圖形。V2.0 字標採 Manrope SemiBold 的原始輪廓；正式 Inter／Noto Sans TC 仍為三套的介面字體基準。可提出 Noto Serif TC 等候選，但只有完成授權、字形、載入成本及 Owner 審閱後才可納入，不能視為公司已核准字體，也不是 Heritage 交付的必要前提。

每套都要有自己的 token、字階／間距、component recipe、Header／Footer、Hero、頁面 composition 及視覺驗收紀錄。可共用原生語意、shadcn／Lucide、資料與行為核心；不得只改顏色、替換 banner 或重排同一組 class 就宣稱完成一套系列。

## 2. 三套版面與使用情境

| 維度 | Modern／現代專業 | Heritage／懷舊復古 | Luxury／奢華精品 |
| --- | --- | --- | --- |
| 定位 | 保留現有企業科技官網 | 編輯式、工藝感、紙本閱讀節奏 | 克制、精準、大留白與展覽式觀看 |
| Header | 現有水平導覽／手機 disclosure | 刊頭式品牌區＋分隔線導覽；手機明確目錄 | 精簡品牌列＋可鍵盤操作的導覽；不用只有圖示的隱藏入口 |
| Hero | 保留現有版型、內容與 CTA | 左右不等寬的編輯版面、標題／導讀／章節索引 | 大標題與單一主焦點、少量文字、獨立 CTA 區 |
| 服務 | 現行五分類、卡片與頁內細項 | 編號服務目錄，摘要與細項雙欄，窄螢幕自然堆疊 | 分段服務敘事與獨立詳情面板，避免把 Modern 卡片換深色 |
| 作品 | 保留現行品牌展示與規劃區分 | 圖說／來源／狀態構成的編輯清冊 | 大圖展示、留白與短資訊列，狀態及來源仍完整可見 |
| 合作方式 | 現有步驟與段落 | 章節序列；編號只代表流程，不冒充公司歷史年表 | 精簡步驟與可展開細節，內容及條件不刪減 |
| CTA | 原詢價與方案入口 | 編輯側欄或段尾行動框 | 獨立高對比行動區，不把功能藏進裝飾文字 |
| Footer | 原結構與完整已發布目錄 | 刊尾分欄目錄／署名 | 克制的品牌尾段＋分組網站索引，不能省略可及性目錄 |
| 手機 | 保留現行互動 | 章節標題、正文與圖片一欄閱讀 | 留白縮減至可用尺度，保留操作密度與可見導覽 |

Home／About／Services／Solutions／Portfolio／Contact／Quotation 及作品詳頁都要套用各自頁面編排。相同內容可分區、分欄與展開，但服務範圍、來源、限制、參考價格、Planned 狀態與實際 CTA 必須完整，不以「奢華極簡」刪除必要資訊。

### Modern 相容基準

Modern 不重新設計。現行 `src/app/globals.css`、`src/components/ui/`、原 layout／sections 為基準；初始八色 token 保留。Quotation 的正式色票範圍及標準 A4 摘要保留，不能因新增 Modern facade 回退到全站初始色票。

現有字階、容器、陰影、圓角與導覽行為逐項記錄後沿用。DC-003 前後指定同環境截圖及 DOM／內容比較；只接受原樣搬移，差異必須可解釋。DC-006 的 Switcher／新增目錄另列允許差異，不擴張為整站重畫。

### Heritage 版型要求

以章節、細分隔線、圖說、編號與不對稱編輯欄建立特徵。可用 CSS 裝飾紙感，正文區保持乾淨；不下載未授權材質，不杜撰舊照片、創立年份、世代傳承或客戶故事。圖片原貌、署名與來源限制不變。首次原型需同時提出桌面雙欄與手機單欄，不能先做桌面再硬縮。

### Luxury 版型要求

以層級、節奏與視覺焦點形成精品感。每段只有清楚的主行動；大型作品圖片仍用真實現有媒體。禁止全螢幕自動影片、強制輪播、游標特效、金色 Logo 或需要 hover 才能找到內容的導覽。深色頁面、表單、瀏覽器 autofill、focus 與反白 Logo 都要獨立驗收。

## 3. Token 提案與隔離

以下 Heritage／Luxury 數值是**展示主體提案**，不是修改公司標準色票的授權；對比亦未經本輪介面實測，不得寫成已通過。Modern 列為既有值，不因此表覆寫現況。

| 角色 | Modern 現況 | Heritage 提案 | Luxury 提案 |
| --- | --- | --- | --- |
| 頁面底色 | #FFFFFF | #F4E9D8 紙色 | #0C1017 墨黑 |
| 內容表面 | #F5F7FB | #FFF9F0 | #151B24 |
| 主標／主要文字 | #101A33／#172033 | #2D241E | #F5F1E8 |
| 次要文字 | #667085 | #705D4A | #B8B1A5 |
| 品牌互動色 | #3157D5 | 正式 Electric Blue #2563EB | 正式 Cyan #06B6D4／Electric Blue，依表面實測 |
| 裝飾強調 | #19B8D5 | #8A3B2E／#B58A4C | #C8A96B 金色 |
| 裝飾邊框 | #E4E8F0 | #D5C7B1 | #3A404A |
| 功能性控制邊界候選 | 沿既有控制項／focus 驗收 | #806B55 | #8B95A5 |

裝飾色不直接用作小字、input 邊界或白字按鈕。新系列須對每個實際背景測量一般文字至少 4.5:1、大字至少 3:1、必要控制邊界／focus 至少 3:1；選取狀態另有文字／勾號。錯誤、成功、disabled、hover、active、focus-visible、loading、selected、empty 各有明確 recipe；不能用「已寄出」當本機草稿的成功狀態。

Token 契約必須完整涵蓋：背景、surface／card／popover、foreground、muted、primary／secondary／accent 與各 foreground、border／input、ring、destructive／錯誤文字、disabled、selection、字體／字階／行高、容器／間距／圓角／陰影及 motion。使用新系列 namespace remap 語意值，不在全域 root 或 Modern tokens 上覆寫。共享品牌原始值與主題呈現別名分開，禁止三份價格與品牌事實進入 token 檔。

## 4. 排版、間距、元件與動態

| 規則 | Modern | Heritage 提案 | Luxury 提案 |
| --- | --- | --- | --- |
| 字體 | 現有 Inter／Noto Sans TC | 相同基準，以章節層級／字重／圖說形成編輯感 | 相同基準，以大標、字重與留白形成焦點 |
| H1／手機 | 原值 | 52／36px 起的響應字階 | 64／36px 起的響應字階，長繁中標題可換行 |
| 正文 | 原值 | 至少 16px，行高 1.7，單欄約 28～40 個中文字寬 | 至少 16px，行高 1.7；不以超小字表達關鍵條件 |
| 容器 | 原容器規範 | 最大約 1180px，左右不等分欄 | 最大約 1280px，作品可獨立全寬區 |
| 間距 | 原值 | 4px 基礎節奏，段間約 48～80px | 4px 基礎節奏，桌面段間約 72～112px；手機約 40～64px |
| 圓角／邊線 | 原值 | 小圓角或直角，分隔線比陰影重要 | 精準小圓角、細邊線；金色僅有限裝飾 |
| 動態 | 保留原值 | 約 120～160ms，必要狀態轉場 | 約 160～240ms，非必要動態可完全取消 |

尺寸是原型起點，不使用固定高度裁切內容；320px、長標題、200% zoom／文字間距及使用者字體設定優先。Reduced Motion 時取消非必要位移、淡入及平滑捲動，不延遲 CTA 或核心資訊。品牌字型只建置時取得並自託管，不新增瀏覽器第三方字體請求。

元件各套至少包含：品牌 Header／Mobile Navigation、Hero、Section heading、服務目錄／卡片、作品預覽／圖說、狀態 Badge、Button／Link、Disclosure、Contact fields／error summary／preview、Quotation radio／checkbox／totals、Footer directory。共享低階行為可依賴現有 UI primitives；各套不能複製驗證與計算再維護三份。

## 5. 可及性與素材

- 每頁一份 h1、main、skip link 及適當地標；heading 順序依資訊而非字級決定。
- 連結與按鈕有名稱、可見 focus、可鍵盤操作；目標尺寸以 44px 為設計起點，至少符合當次 WCAG 2.2 AA 適用條件，不因極簡或復古縮小手機操作區。
- 選取、錯誤、Planned／展示性質不用顏色單獨傳達；表單 label、disabled 原因、錯誤摘要 focus 與輸入保留沿用共享核心。
- 跨頁及風格切換的 focus、手機選單關閉／Escape／外部點擊、dialog／disclosure 的讀屏資訊必須實測；不以 DOM 樹代替真人讀屏。
- 不做專屬假案例圖片、假客戶證言或暗示第三方品牌已採購 XK；原模板署名與限制完整保留。
- A4 用標準企業摘要，三套數值、選取、條款及兩個 QR 一致；最壞 17 項加購與 40／60 字輸入，普通／Pages 各產真 PDF 確認一頁 A4、全部內容在頁內與 QR 可解碼。

## 6. 獨立版面驗收

DC-004／DC-005 的桌面與手機截圖須證明至少四項構圖差異：Hero、服務、作品、合作／CTA；Header／Footer 亦有各自 recipe。不以像素差異百分比、換色或隨意改間距充數，需逐項說明資訊如何重新編排。

同一服務、作品 ID 與試算選擇，在三套的文字事實、狀態、外鏈與金額完全一致；內鏈的 page key／slug／語意目的相同，href 依系列 resolver 轉換。條件／來源不能因外觀被藏掉。視覺比較、內容等價、可及性與功能驗收是四個獨立門檻，缺一不可。設計 Owner 需核對新增色彩與公司外框的邊界後才可公開新系列。
